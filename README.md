# Account Invoice Header Note

A rich text note above the invoice lines &mdash; the counterpart to Odoo's
*Terms and Conditions*, which only ever print below them.

Type a greeting, a delivery reference, a project or contract number directly
above the lines, and it prints there too. No more squeezing introductory text
into the first invoice line.

If you would rather pick the text from a list of reusable, conditional
templates than type it per invoice, look at OCA's
[account_comment_template](https://github.com/OCA/account-invoice-reporting/tree/19.0/account_comment_template)
instead. Both can be installed together.

see [account_invoice_header_note/README.md](./account_invoice_header_note/README.md)
