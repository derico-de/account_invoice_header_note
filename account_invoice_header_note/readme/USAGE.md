1. Open a customer invoice or vendor bill.
2. On the *Invoice Lines* tab, type into the note area directly above the
   lines. It is a rich text field, so bold, lists and links are available.
3. Print the invoice — the note is rendered above the lines table.

The note is copied when an invoice is duplicated and stays editable after
posting, exactly like the *Terms and Conditions* below the lines.

Leaving the field empty prints nothing at all — no empty paragraph, no extra
spacing.
